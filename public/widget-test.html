🧪 Widget Test Page

This page demonstrates the Assistra chat widget. Look for the chat bubble in the bottom-right corner.

How it works

The widget is loaded via a single script tag with your API key. It automatically fetches your chatbot configuration (name, colors, welcome message) and renders a beautiful chat interface.

Integration Code

<script 
  src="https://dev.assistra.app/widget.js" 
  data-api-key="sk_live_YOUR_KEY"
  async>
</script>
